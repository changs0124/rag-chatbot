## 탈락 표

| 후보 | 무효화 사유 | 전제가 바뀌어도 성립? |
|------|-------------|------------------------|
| Spring Boot 4.1.0 | MyBatis SB4 스타터(4.1.0)가 2026-07-16 릴리스로 안정성 검증이 얕고, 참조 구현과 라인이 달라 초기 리스크가 큼. EOL 보안 공백은 목업/개발 단계라 트레이드오프로 수용 | **아니오(시간 의존)** - 성숙하면 사유 소멸. 그래서 두 안을 사용자에게 제시해 3.5.16을 택했고, **"SB4 업그레이드 재검토"를 미결 표에 등재**함 |
| MySQL / MariaDB | uuid 네이티브 타입 미지원(CHAR(36)/BINARY(16) 우회) + 참조 구현 Postgres 스키마와 불일치로 이식 비용 발생 | 예 - uuid/jsonb 활용과 참조 정합성은 오래가는 기준 |
| 공식 openai-java SDK 4.45.0 | Vector Stores API가 아직 `OpenAI-Beta` 헤더를 요구(완전 GA 미확인)하고, SDK 마이너 업데이트마다 시그니처 변화 위험. 참조 검증 패턴(RestClient) 미활용 | **아니오(부분/시간 의존)** - SDK가 GA로 안정화되면 유리. **2차 폴백으로 유지**하고 미결 표에 전환 트리거 등재 |
| 서버 세션(쿠키) | SSE `fetch`·모바일·수평 확장에서 stateless JWT가 유리. 상태 저장소 불필요 | 예 - stateless 요구는 오래감 |
| EventSource(SSE 표준 API) | Authorization 헤더·POST 불가라 JWT 인증과 구조적으로 불일치 | 예 - 인증 헤더 필요성은 오래감 |
| Tailwind CDN 방식 | 실앱 번들의 공식 권장 경로가 아님(플러그인 방식). CDN은 Supernova 디자인 시안 산출용 | 예 - 빌드 파이프라인 표준은 오래감 |

> **탈락 사유가 "아니오(시간 의존)"인 2건**(SB4.1.0 · 공식 SDK)은 가이드 통과 조건상 그대로 두면 안 되므로, **미결 표에 "재검토 트리거"로 등재**해 처리함. 두 안 모두 사용자에게 제시 후 현 채택안을 승인받음.
