# 04_런칭 - rag-chatbot

> 8단계 런칭 표를 **2단계에서 미리 만들어 둠**(가이드 지시). 8단계에서 만들면 이미 늦음 - 한 곳만 빠져도 조용히 실패함. 각 항목은 실행 전 되돌리는 방법·소요·비용을 채움. 시크릿 값은 여기 적지 않고 보관 위치만 적음(`docs/02_운영.md` 접근 권한 표).

## 런칭 표

| 손댈 지점 | 담당 | 상태 | 확인 방법 | 되돌리는 방법 | 되돌림 소요 | 월 비용 |
|-----------|------|------|-----------|---------------|-------------|---------|
| 실 OpenAI API KEY 발급·등록 | changs0124 | 대기 | live 응답이 실제로 나옴 · M2 스파이크 실행(출처 스키마 + 진행 단계 원천 이벤트·체감 구간, 이관-6·7) | **폐기·재발급**(회수 불가 부류 - 되돌림 아님) | 즉시 | 사용량 기반 |

> [!warning] 되돌림 비용이 비대칭인 조작
> API KEY·Store 데이터는 되돌림이 아니라 **폐기·로테이션** 절차가 필요함(이미 나간 것은 회수 불가). 색인 차단 해제·실도메인 연결은 켜는 것은 즉시지만 끄는 것은 DNS TTL·크롤러 재색인 때문에 며칠 걸릴 수 있음.
