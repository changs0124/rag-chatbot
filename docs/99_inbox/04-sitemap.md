> **화면 수가 적다.** 사내 도구라 기능이 채팅 하나에 몰려 있고, 나머지는 로그인·마이페이지뿐이다.
> 일반적인 GNB/LNB 구조가 없으며, 이 문서는 그 사실 자체를 기록한다.
>
> 라우팅 정본은 `frontend/src/App.tsx` 다.

## 1. 전체 구조 개요

```
rag-chatbot
├── 공개 영역 (GUEST)
│   └── 로그인 · 회원가입 (SCR-AUTH-001)   /login
│       └── 한 화면에서 탭으로 전환한다 (별도 URL 없음)
│
├── 회원 영역 (USER 이상)
│   ├── 채팅 (SCR-CHAT-001)               /
│   │   ├── 사이드바 — 대화 목록 · 새 대화 · 제목 변경 · 삭제
│   │   ├── 메시지 목록 — 답변 · 출처 각주 · 첨부 썸네일
│   │   ├── 입력창 — 텍스트 · 첨부 카드 · 전송/정지
│   │   └── 확대 보기 모달 (SCR-CHAT-002) — URL 없는 오버레이
│   │
│   └── 마이페이지 (SCR-MY-001)            /me
│       ├── 이름 변경
│       ├── 비밀번호 변경
│       ├── 테마 (라이트 · 다크 · 시스템)
│       └── 관리 ─────────────── ADMIN 에게만 노출
│
└── 관리자 영역 (ADMIN)  ← 미구현
    └── 문서 관리 (SCR-ADMIN-001)          /admin
        ├── 문서 업로드 · 목록 · 삭제
        └── 사용자 목록 · 비밀번호 초기화 (SCR-ADMIN-002 섹션)
```

**관리자 영역에 대시보드를 두지 않는다.** 보여줄 지표가 없다 — 사용량 집계는 REQ-OPS-001이
데이터를 쌓은 뒤에 무엇을 볼지 정한다. 빈 대시보드를 미리 만들지 않는다.

## 2. 화면 목록

| ID | 화면명 | URL | 접근 권한 | 상태 | 설명 |
|----|--------|-----|---------|------|------|
| SCR-AUTH-001 | 로그인 · 회원가입 | `/login` | GUEST | 구현됨 | 한 화면에서 탭 전환 |
| SCR-CHAT-001 | 채팅 | `/` | USER+ | 구현됨 | 사이드바 + 메시지 + 입력창 |
| SCR-CHAT-002 | 첨부 확대 보기 | — | USER+ | 구현됨 | URL 없는 모달. 전송 전·후 공용 |
| SCR-MY-001 | 마이페이지 | `/me` | USER+ | 구현됨 | 이름 · 비밀번호 · 테마 |
| SCR-ADMIN-001 | 문서 관리 | `/admin` | ADMIN | **미구현** | 업로드 · 목록 · 삭제 |
| SCR-ADMIN-002 | 사용자 관리 | `/admin` 내 섹션 | ADMIN | **미구현** | 목록 · 비밀번호 초기화 |
| — | 그 외 모든 경로 | `*` | — | 구현됨 | `/` 로 리다이렉트 |

**SCR-ADMIN-002에 별도 URL을 주지 않는다.** 표 하나 분량이라 화면을 나눌 이유가 없다.
관리 대상이 늘어나면 그때 분리한다.

## 3. 네비게이션 구조

### GNB — 없음

전역 네비게이션 바가 없다. 채팅 화면이 전체 화면을 쓰고, 이동은 아래 두 지점으로만 일어난다.

| 위치 | 이동 대상 | 노출 조건 |
|------|---------|---------|
| 사이드바 하단 사용자 영역 | `/me` | 로그인 상태 |
| 마이페이지 상단 뒤로가기 | `/` | 항상 |
| 마이페이지 「관리」 섹션 | `/admin` | **`role=admin` 일 때만** |
| 관리 화면 상단 뒤로가기 | `/me` | 항상 |

### LNB — 사이드바 (채팅 전용)

채팅 화면의 사이드바는 네비게이션이 아니라 **대화 목록**이다. 폭 조절이 가능하고 `md` 미만에서는
오버레이 드로어로 바뀐다.

| 항목 | 동작 |
|------|------|
| 새 대화 | 활성 대화를 비우고 새 턴을 시작한다. 서버 호출은 첫 전송 시점 |
| 대화 항목 | 선택 시 메시지를 불러온다. **돌던 스트림은 끊는다** |
| 제목 변경 | 인라인 편집 |
| 삭제 | 확인 모달 후 삭제. OpenAI 리소스 정리를 동반한다 |

## 4. 공통 컴포넌트

| 컴포넌트 | 노출 위치 | 설명 |
|---------|---------|------|
| `ProtectedRoute` | `/` · `/me` · (`/admin`) | 미인증이면 `/login` 으로 보낸다 |
| `ErrorBoundary` | 앱 전체 | 렌더 오류를 잡는다. **관측 도구 연결 지점만 있고 지금은 콘솔 기록뿐** |
| `ConfirmModal` | 대화 삭제 · (문서 삭제) | 파괴적 동작의 확인 |
| `TextInput` | 로그인 · 마이페이지 | 입력창 클래스 중복을 묶은 것 |
| `ThemeProvider` | 앱 전체 | 시스템 설정 해석을 단독으로 담당한다 |
| `AuthContext` | 앱 전체 | 토큰·사용자 보유. 401 시 로그인으로 되돌린다 |

**Header · Footer 가 없다.** 채팅이 전체 화면을 쓰는 구조라 둘 자리가 없고, 사내 도구라
푸터에 넣을 정보도 없다.

## 5. 화면 없이 존재하는 경로

URL을 갖지 않지만 사용자에게 노출되는 것들이다. 화면 목록에서 빠지기 쉬워 여기 적는다.

| 경로 | 성격 | 비고 |
|------|------|------|
| `GET /api/files/{id}?token=…` | 첨부 이미지 원본 | `<img src>` 가 직접 부른다. 서명 토큰 TTL 15분 |
| `POST /api/chat` (SSE) | 답변 스트림 | 화면 전환 없이 같은 화면에서 소비된다 |

| `/` | X → `/login` | O | O |
| `/me` | X → `/login` | O | O |
| `/admin` | X → `/login` | **X → `/`** | O |
