> **범위 한정** — 첨부 미리보기(FEAT-CHAT-001 · 002 · 003)가 바꾸는 **입력창 카드 · 확대 모달 · 드롭 오버레이만** 그린다.
> 채팅 화면의 나머지 배치는 이미 구현된 그대로다.

## 1. 설계 기준

- **브레이크포인트** : Tailwind 기본값. 이 화면이 실제로 가르는 지점은 `md`(768px) 하나다 —
  `md` 이상은 사이드바 상주, 미만은 오버레이 드로어(`frontend/src/pages/ChatPage.tsx`)
- **그리드** : 없음. 본문은 `max-w-3xl` 중앙 정렬 한 줄기다
- **디자인 도구** : 없음 (마크다운 설명 + Tailwind 유틸리티 클래스)
- **다크 모드** : 모든 신규 요소는 `dark:` 접두를 함께 둔다. `prefers-color-scheme` 을 직접 보지 않는다
- **참고한 것** : ChatGPT · Claude 채팅 입력창. 이미지는 파일명 없는 정사각 카드

## 2. 화면별 와이어프레임

### SCR-CHAT-001: 채팅

**URL:** `/`

#### 2-1. 입력창 첨부 카드 (FEAT-CHAT-001)

**변경 전 (지금)**

```
┌──────────────────────────────────────────────┐
│ [🖼] photo_0001.jpg ⊗ │ [🖼] IMG_22.png ⊗   │   ← 아이콘 + 파일명 칩
├──────────────────────────────────────────────┤
│ [+]  메시지를 입력하세요              [ ↑ ]  │
└──────────────────────────────────────────────┘
```

**변경 후 — 상태 3가지**

```
┌──────────────────────────────────────────────┐
│  ┌────┐⊗  ┌────┐⊗  ┌────┐⊗                  │  ← ⊗ 는 카드 모서리에 걸침
│  │■■■■│   │▨▨▨▨│   │ ⚠  │                   │
│  │■■■■│   │ ◐  │   │재시도│                  │
│  └────┘   └────┘   └────┘                    │
│   완료     업로드중   실패                     │
├──────────────────────────────────────────────┤
│ [+]  메시지를 입력하세요              [ ↑ ]  │
└──────────────────────────────────────────────┘
     ■ = 썸네일  ▨ = 흐리게 처리한 썸네일  ◐ = 진행 표시
```

- 업로드 중인 카드가 하나라도 있으면 **보내기 버튼이 비활성**이다
- 이미지가 아닌 파일은 카드조차 만들지 않는다(버림). `+` 메뉴도 **사진 · 카메라** 둘뿐이다

**Mobile (~767px)** — 카드 크기는 같고 줄바꿈만 늘어난다. 카드가 파일명을 안 쓰므로 좁은 화면에서도 한 줄에 3~4장 들어간다.

**UI 컴포넌트:**

| 컴포넌트 | 타입 | 설명 |
|---------|------|------|
| 첨부 카드 | `button` | 64px 정사각 · `object-cover` · 둥근 모서리. 누르면 확대 |
| 썸네일 | `img` | `src` 는 로컬 objectURL. `alt` 에 파일명 |
| 제거 버튼 | `button` | 카드 **우상단 모서리에 겹침**. `aria-label="첨부 제거"` |
| 진행 표시 | `div` | 업로드 중 카드 위에 반투명 겹침 + 스피너 |
| 실패 표시 | `div` | 경고 아이콘 + `재시도` 버튼. 서버 메시지는 title 로 |

**인터랙션:**

| 동작 | 결과 |
|------|------|
| 이미지 선택 · 촬영 · 드롭 · 붙여넣기 | 카드 즉시 생성 + 업로드 시작 |
| 카드 클릭 | 확대 모달 열림 (업로드 중이어도 열린다) |
| ⊗ 클릭 | 카드 제거 · 진행 중이면 요청 중단 · 올라갔으면 서버 삭제 · objectURL 회수 |
| 재시도 클릭 | 같은 파일로 업로드를 다시 시작 |
| 전송 | 카드 목록 비움 + objectURL 전부 회수 |

#### 2-2. 확대 보기 모달 (FEAT-CHAT-002)

```
┌──────────────────────────────────────────────┐
│▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒[ ⤓ ][ ✕ ]│  ← 내려받기 · 닫기
│▒▒                                        ▒▒▒│
│▒▒  ‹  ┌────────────────────────┐  ›       ▒▒│  ← 2장 이상일 때만 좌우 버튼
│▒▒     │                        │           ▒▒│
│▒▒     │      원본 이미지        │           ▒▒│  ← object-contain (잘라내지 않음)
│▒▒     │                        │           ▒▒│
│▒▒     └────────────────────────┘           ▒▒│
│▒▒                  2 / 3                   ▒▒│  ← 묶음이 2장 이상일 때만
│▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒│
└──────────────────────────────────────────────┘
        ▒ = 반투명 검정 배경(클릭하면 닫힘)
```

**Mobile (~767px)** — 같은 구조에 여백만 줄인다. 좌우 버튼은 화면 양 끝에 붙인다.
손가락 제스처가 브라우저 기본 동작에 먹히지 않도록 이미지에는 `touch-action: none` 을 준다.

**UI 컴포넌트:**

| 컴포넌트 | 타입 | 설명 |
|---------|------|------|
| 배경 | `div` | 반투명 검정. 클릭하면 닫힘. `aria-hidden="true"` |
| 원본 이미지 | `img` | `max-h`/`max-w` 로 화면 안에 맞춤. **잘라내지 않는다** |
| 좌우 버튼 | `button` | 묶음이 2장 이상일 때만. 양 끝에서는 비활성 (순환 없음) |
| 위치 표시 | `span` | `현재/전체`. 2장 이상일 때만 |
| 내려받기 | `button` | `aria-label="내려받기"`. blob 으로 받아 저장 |
| 닫기 | `button` | `aria-label="닫기"` |
| 컨테이너 | `div` | `role="dialog"` · `aria-modal="true"` |

**인터랙션:**

| 동작 | 결과 |
|------|------|
| 카드 · 말풍선 썸네일 클릭 | 그 묶음을 들고 해당 위치에서 열림 |
| ← / → 키, 좌우 버튼 | 이전/다음 이미지. 양 끝에서는 반응 없음 |
| 두 손가락 벌리기/오므리기 | 1~4배 확대. 1배 아래로는 줄지 않음 |
| 확대 상태에서 끌기 | 이미지가 따라 움직임(1배에서는 반응 없음) |
| 더블클릭 · 더블탭 | 1배 ↔ 2배 |
| Esc · 배경 클릭 · 닫기 버튼 | 닫힘 |
| 내려받기 | 파일로 저장. 실패하면 조용히 끝내고 모달은 유지 |
| 닫은 뒤 | 채팅 화면·스크롤 위치 그대로. 스트리밍 중이면 스트림도 그대로 |

**말풍선 쪽 변경 (같은 화면):**

```
┌ 내 말풍선 ────────────────┐
│ [■■■■] [■■■■]            │  ← 96px 썸네일이 button 으로 감싸짐
│ 이 사진 설명해줘            │     커서 포인터 · 포커스 링 표시
└───────────────────────────┘
```

#### 2-3. 드롭 오버레이 (FEAT-CHAT-003)

파일을 채팅 화면 위로 끌면 대화 영역 전체를 덮는다.

```
┌──────────────────────────────────────────────┐
│ ╔══════════════════════════════════════════╗ │
│ ║                                          ║ │  ← 점선 테두리 + 반투명 막
│ ║            여기에 놓아 첨부                ║ │
│ ║                                          ║ │
│ ╚══════════════════════════════════════════╝ │
├──────────────────────────────────────────────┤
│ [+]  메시지를 입력하세요              [ ↑ ]  │
└──────────────────────────────────────────────┘
```

**인터랙션:**

| 동작 | 결과 |
|------|------|
| 파일을 끌고 화면에 진입 | 오버레이 표시 |
| 화면 밖으로 이탈 | 오버레이 걷힘 (진입/이탈 **카운터**로 판정 — 자식 요소 경계에서 깜빡이지 않게) |
| 놓음 | 오버레이 걷고 카드 생성 + 업로드 시작 |
| 파일이 아닌 것을 끔 | 오버레이를 띄우지 않음 |
| 입력창에 이미지 붙여넣기 | 카드 생성 + 업로드 시작. 텍스트만 있으면 평소대로 입력됨 |
