## 작업 요약

`CONVENTIONS.md` 의 필수 체크 목록이 **축약형임을 명시하고 정본을 가리키게** 했다.
전체 문자열로 바꾸는 쪽은 고르지 않았다.

## 왜 전체 문자열로 바꾸지 않았나

| | 1안 (전체 문자열) | **2안 (축약 명시 + 정본 안내)** |
| --- | --- | --- |
| 옮겨 적기 | 안전 | 정본을 봐야 한다 |
| 잡 이름이 사는 곳 | `ci.yml` · ruleset · **문서 = 셋** | `ci.yml` · ruleset = **둘 그대로** |
| 늘어난 사본을 지키는 게이트 | **없음** | 해당 없음 |

`CONVENTIONS.md:147` 이 밝히듯 `check-doc-versions.sh` 는 「버전이 아닌 **목록형 서술**(CI 잡
목록·이 게이트 목록 자체가 그렇다)」을 **일부러 제외**한다. 1안이 들이는 사본은 어느 게이트도
지키지 않는다.

그리고 [#105](https://github.com/changs0124/rag-chatbot/issues/105) 항목 5 가 허용 목록을 놓고
같은 거래를 이미 거절했다 — *"고치면 허용 목록 사본이 **네 번째로 늘어** 사슬이 길어진다"*.

## 넣은 내용

축약 목록 **바로 뒤**(`:166`)에 붙였다. 떨어뜨리면 목록만 읽고 넘어간다.

- 위 목록은 축약이고 실제 context 는 `ci.yml` 의 잡 `name:` 전체 문자열이라는 사실
- **여기에 옮겨 적지 않는 이유** — 사본이 셋으로 늘고 지킬 게이트가 없다(#105 선례)
- **복원해야 하면 문서가 아니라 정본에서 뽑는다** : `gh api …/rules/branches/main --jq …`
- 규칙조차 못 읽는 상황이면 `ci.yml` 의 `name:` 을 쓴다

## 검증

**적어 둔 명령을 문서에서 그대로 추출해 돌렸다.** #170 에서 이 검증이 한 줄 140자 버그를 잡았다.

```console
$ gh api repos/changs0124/rag-chatbot/rules/branches/main \
    --jq '[.[]|select(.type=="required_status_checks").parameters.required_status_checks[].context]'
["backend (test + build + 케이스 수 하한)","frontend (lint + test + build + 케이스 수 하한)", … 7개]
```

| 항목 | 결과 |
| --- | --- |
| 정본 명령 실행 | context 7개 그대로 출력 |
| 배치 | `:164`(축약 목록) → **`:166`(축약 명시)** → 기존 서술 |
| before 0건이던 문자열 | `축약` · `정본` · `rules/branches/main` 각 1건 |
| 문서 게이트 | 전부 통과 · 건너뜀 0건 (shellcheck 를 Docker 로 실제 실행) |

### 사본 수는 0 이 아니라 1 이다 — 숨기지 않고 적는다

`docs/` 안의 전체 문자열이 **before 0건 → after 1건**으로 **늘었다.** 늘어난 것은 설명용 예시
한 번(「예 : `backend` 가 아니라 `backend (test + build + …)`」)이다.

2안이 피하려던 것은 **일곱 개를 목록으로 옮겨 적는 것**이고 그 목록은 만들지 않았다. 사본이
위험한 이유는 「규칙이 바뀌면 같이 고쳐야 하는데 지키는 게이트가 없다」인데, 일곱 중 하나뿐인
예시는 **옮겨 적기의 원본으로 쓰일 수 없어** 그 위험을 만들지 않는다.
그래도 0 은 아니다 — 1안을 골랐으면 7건이었을 것이라는 점에서 차이가 의미 있다.

## 증거

캡처가 없다. 문서만 바뀌는 변경이라 앱 화면이 없다. 대신 **문서에서 추출한 명령의 실제 실행
출력**과 **사본 수 계수**를 남겼다 — 후자가 2안을 고른 근거 자체다.

| 파일 | 내용 |
| --- | --- |
| `before/01-shorthand-before.txt` | 고치기 전 해당 줄 · 사본 0건 · 축약/정본 표시 0건 |
| `after/01-shorthand-after.txt` | 정본 명령 실행 결과 · 사본 수(정직하게 1건) · 배치 · 게이트 |
