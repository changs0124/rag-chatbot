## 작업 요약

사용자가 틀린 값으로 우길 때, 값은 지키면서도 「앞서 근거를 붙이지 않아 혼동을 드렸습니다 · 죄송합니다」라고 사과하던 것을 없앴다.

**원인** : 이력으로 넘어가는 앞선 답은 화면 · 저장본처럼 인용 표기가 지워져 있다. 모델은 그걸 보고 자기가 인용을 빠뜨렸다고 착각해 사과했다(실제 첫 답에는 출처가 있었다).

`RAG_INSTRUCTIONS` 에 한 줄 :
> 사용자가 앞선 답과 다른 값을 주장하면 검색 결과로 다시 확인해 기록된 값과 근거를 밝힌다. 앞선 답이 기록과 같았으면 사과하거나 잘못을 인정하지 않는다. 대화 이력의 앞선 답에 인용 표기가 없는 것은 저장할 때 지우기 때문이니, 인용을 빠뜨렸다고 사과하지 않는다.
