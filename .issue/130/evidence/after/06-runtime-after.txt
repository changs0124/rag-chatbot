## before / after 한눈 대조
  항목                 before              after
  -------------------  ------------------  ----------------------------------------
  no-new-privileges    없음 (셋 다)        셋 다 적용
  cap_drop             없음 (기본 14개)    app 0개 / db 4개 / cloudflared 0개
  read_only            없음                app 적용 (+ /tmp tmpfs 64m)
  pids_limit           없음                db 128 / app 256 / cloudflared 64
  로그 회전            app 만              셋 다 (10m x 3)
  네트워크             기본 하나에 셋 다   backend(db+app) / edge(app+cloudflared)
  cloudflared 이미지   :latest (표류)      @sha256:b269e8ab... 고정
  서버 .env 권한       확인하지 않음       deploy.sh 프리플라이트가 600 으로 고정

## 범위에서 제외한 것 — 숨기지 않고 적는다
  1) memswap_limit / 스왑 : 판단 근거가 pd-standard 의 쓰기 45 IOPS 라 개발 PC 에서 재현 불가.
     배포 후 부하 측정으로 미뤘다. 이슈는 열어 둔다.
  2) TUNNEL_TOKEN 을 Docker secret / credentials 파일로 : Cloudflare 쪽 자료가 필요하다.
     docker inspect 평문 노출은 아직 열린 문제이며, 문서에 「출력을 공유하지 말 것」을 적었다.
  3) cloudflared 정상 동작 : 토큰이 자리표시자라 확인 불가. 설정 적용과 실패 원인만 확인했다.
  4) postgres:16-alpine 다이제스트 고정 : 이슈 범위가 cloudflared 였다. 별도 판단 대상.
