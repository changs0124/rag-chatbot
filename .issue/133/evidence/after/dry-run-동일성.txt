세 값을 지정하면 기존과 완전히 동일하게 동작하는가

$ DEPLOY_HOST=… DEPLOY_ZONE=… DEPLOY_PROJECT=… bash scripts/deploy.sh --dry-run > after.txt
$ diff before.txt after.txt
$ echo $?
0

before.txt 는 이 워크트리를 만든 직후, 파일을 하나도 고치기 전에 같은 세 값으로 뜬 출력이다.
diff 가 비었다 = 배포 경로의 동작은 한 줄도 바뀌지 않았다. 바뀐 것은 "값이 없을 때" 뿐이다.

(출력 5줄에 인스턴스명·존·프로젝트 ID 가 그대로 찍히므로 파일 자체는 증거에 싣지 않는다.
 제거가 이 이슈의 목적이라 증거로 다시 공개하지 않는다.)
