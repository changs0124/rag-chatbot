커밋은 원인이 달라 둘로 나눴다.

| 커밋 | 원인 |
|---|---|
| `chore(deploy): 배포 대상 기본값을 없애고 필수 지정으로 바꾼다` | 공개 전환을 위한 식별자 제거 |
| `docs(deploy): DEPLOY_DIR 기본값 표기를 스크립트와 맞춘다` | #129 가 남긴 문서 표류 |

## 함정 둘 — 이슈가 지적한 대로 피했다

**① `--dry-run` 이 검사를 비껴간다**

검사를 `preflight` 안에 넣으면 안 됐다. `--dry-run` 분기가 `preflight` 호출보다 먼저 `exit 0` 하기 때문이다. 그랬다면 환경변수 없이 `--dry-run` 을 돌렸을 때 `호스트   ( / )` 라는 빈 계획을 출력하고 **정상 종료**했을 것이다. 하필 `docs/04_tasks/backlog.md` 와 `current-sprint.md` 가 「`--dry-run` 을 먼저 볼 것」을 배포 첫 동작으로 지정하고 있어, 처음 배포하는 사람이 가장 먼저 밟는 경로가 정확히 그 사각지대다. **검사는 인자 파싱 직후에 뒀다.**

**② `set -u` 와 충돌**

`set -euo pipefail` 아래에서 기본값을 문자 그대로 지워 `${DEPLOY_HOST}` 로 두면 변수 정의부에서 `unbound variable` 로 **안내 없이** 죽는다. `${DEPLOY_HOST:-}` 로 받고 빈 값을 따로 검사한다.

## 전후

**변경 전** — 아무 설정 없이 `--dry-run` 이 실 배포 대상을 담은 계획을 출력하고 `exit 0`

```
$ bash scripts/deploy.sh --dry-run
호스트   <인스턴스명> (<존> / <프로젝트 ID>)
원격 경로 deploy
...
$ echo $?
0
```

**변경 후** — 실행·`--dry-run` 둘 다 안내와 함께 `exit 2`. 빠진 것만 모아서 한 번에 알린다

```
$ bash scripts/deploy.sh --dry-run
배포 대상이 지정되지 않았다. 아래 환경변수를 넣고 다시 실행할 것 :
  - DEPLOY_HOST(인스턴스 이름)
  - DEPLOY_ZONE(영역)
  - DEPLOY_PROJECT(GCP 프로젝트)
$ echo $?
2

$ DEPLOY_ZONE=<존> bash scripts/deploy.sh --dry-run      ← 일부만 준 경우
배포 대상이 지정되지 않았다. 아래 환경변수를 넣고 다시 실행할 것 :
  - DEPLOY_HOST(인스턴스 이름)
  - DEPLOY_PROJECT(GCP 프로젝트)
```

## 검증

| 항목 | 결과 |
|---|---|
| 세 값 지정 시 `--dry-run` 출력이 변경 전과 동일 | `diff` 0줄 |
| 미설정 시 실행 / `--dry-run` | 둘 다 `exit 2` + 안내 |
| 일부만 지정 | 빠진 것만 나열 |
| `bash -n scripts/deploy.sh` | 통과 |
| `bash scripts/check-all.sh docs` | 통과 (참조 225 수집·215 실재 / 섹션 24) |
| 두 값으로 `git grep` (`.issue` 제외) | 0건 |

**문서는 네 자리를 전부 고쳤다** — 표 세 행뿐 아니라 표 위의 "기본값은 현재 서버" 서술과 표 머리 `기본값` 열까지. 셋 중 하나라도 남기면 기본값 없는 표 위에 거짓 문장이 남는다.

## 남는 한계 (의도한 것)

- **이 변경을 잡아 주는 자동 게이트는 없다.** 다섯 게이트 모두 표 *안의 값*을 안 보고, CI 에 `shellcheck`·`bash -n` 이 없다. `DEPLOY_DIR` 표류가 살아남은 이유도 이것이다. 새 게이트 신설은 이 이슈 범위 밖이다
- **인스턴스명·존·개인 이메일은 그대로 공개된다.** `.issue/127/evidence/` 실측 기록과 `.issue/{34,36,38,39}/evidence/` patch 파일에 남아 있고, 둘 다 공개하기로 이미 결정한 대상이다. 위 grep 0건은 "두 값이 추적 파일에서 빠졌다"는 뜻이지 "인프라가 식별 불가능해졌다"는 뜻이 아니다
- **과거 커밋 이력은 건드리지 않았다.** 이력 재작성은 `.issue/` 증거의 커밋 SHA 참조 33개를 죽인다
- **스캔은 시점 스냅샷이다.** public flip 직전 재스캔은 flip 을 실행하는 쪽의 책임이다
