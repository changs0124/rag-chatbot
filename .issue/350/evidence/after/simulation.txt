    | 되돌리려면 (마지막 정상 이미지를 rag-chatbot-backend:previous 로 남겨 두었다) :
    |   cd deploy && sudo docker tag rag-chatbot-backend:previous rag-chatbot-backend:latest && sudo docker compose up -d
    태그 기록 : tag rag-chatbot-backend:previous <- sha256:old
