### 진행 중 발견 — 별도 이슈로 뺀다
관리 화면 삭제가 스토어 연결 해제 요청을 `Content-Type: application/x-www-form-urlencoded` 로 보내 OpenAI 가 400 으로 거절하고,
앱은 경고만 남긴 채 행을 지운다. **지운 문서가 스토어에서는 계속 검색된다** — 이번에도 옛 원문이 남아 번호가 계속 노출됐고,
연결을 JSON 헤더로 직접 끊은 뒤에야 0 이 됐다. 같은 때 「스토어와 동기화」는 File 이 없는 스토어 항목에서 500 으로 멈췄다.
