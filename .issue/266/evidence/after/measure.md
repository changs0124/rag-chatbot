| 단계 | 결과 |
|---|---|
| 로컬 관리 화면으로 마스킹판 업로드 | 201 → completed |
| 옛 파일 관리 화면 삭제 | 204 — **그러나 스토어 연결 해제가 400 으로 조용히 실패**(아래) |
| 옛 파일 스토어 연결 직접 해제 | 200 `vector_store.file.deleted` |
| 스토어 파일 | 2개(마스킹판 클레임 · 매뉴얼) |
| 운영 DB | 옛 행 삭제 204 → 「스토어와 동기화」 added 1 · total 2 |

**발견** : 앱의 삭제가 `DELETE /vector_stores/{id}/files/{id}` 를 `Content-Type: application/x-www-form-urlencoded` 로 보내
OpenAI 가 400(`unsupported_content_type`)으로 거절한다. `deleteQuietly` 가 경고만 남기고 삼켜, 관리 화면에서 지운 문서가
스토어에서는 계속 검색된다. 같은 때 동기화는 File 이 없는 스토어 항목에서 404 를 받아 500 으로 멈췄다. 원인이 달라 별도 이슈로 뺐다.
