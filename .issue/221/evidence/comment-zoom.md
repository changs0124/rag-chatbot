## #221 후속 리포트 — iOS 입력 포커스 확대

**사용자 실기기 보고** : 헤더 고정은 확인. 그러나 ① 입력에 포커스하면 키보드와 함께 입력 칸이 맨 위로 밀리고 ② 포커스를 풀면 좌우 스크롤이 생긴다.

**원인** : 입력 글자가 전부 15px 였다. iOS Safari 는 16px 미만 입력에 포커스하면 화면을 확대하고, 포커스가 풀려도 되돌리지 않는다.
- ① 확대되면 보이는 영역 높이가 CSS px 로 작아지는데, #224 의 높이 맞춤이 그 값을 그대로 루트에 넣어 화면이 짧아졌다 → 입력 칸이 위로 솟음
- ② 확대(≈16/15)가 남아 폭이 넘쳐 가로 스크롤

**변경**
- 메시지 입력 · 제목 수정 · `TextInput`(로그인 · 마이 · 관리) 글자를 모바일 16px · md 이상 15px 로
- 높이 맞춤은 `visualViewport.scale` 이 1 일 때만 — 사용자가 확대한 동안은 루트 높이 · 문서 스크롤을 건드리지 않는다
