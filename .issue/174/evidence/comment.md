종전에는 「저장소 밖 준비물을 기다린다」까지만 있고 **무엇이 그것을 기다리는지**가 없었다.

**VM 상태가 특히 중요하다.** 문서는 「서버 쪽 준비는 끝났다」까지만 적었는데 실제로는 인스턴스가
이미 만들어져 있고 꺼져 있다. 「처음부터 만들어야 하나」와 「켜기만 하면 되나」는 착수 비용이 다르다.

```console
$ gcloud compute instances list
NAME     STATUS      ZONE
free-vm  TERMINATED  us-west1-b
```

`#37` 을 맨 앞에 둔다 — `curl` 한 줄에 2초면 끝나고 결과(200/400)가 배포 판단에 쓰인다.

```text
1) #37 의 curl 한 줄  (400 이면 헤더가 필수였다는 확인, 200 이면 SDK 정합성 개선으로 남는다)

3) #130 의 하드닝을 VM 에서 한 항목씩 재확인 (+ 토큰 넣은 cloudflared 가 실제로 붙는지)
4) #132 착수 — 데이터가 쌓이기 시작한 뒤에 의미가 있다
```

## 중복을 없애면서 내용을 잃지 않았다

`current-sprint.md`(8-20행)와 `backlog.md`(25-31행) **양쪽에** 거의 같은 준비물 목록이 있었다.
한쪽만 고치면 갈라지는 상태였다.

**`current-sprint.md` 를 정본으로 골랐다.** 근거는 두 문서가 스스로 적어 둔 구분이다 —
`backlog.md` 는 「아직 착수하지 않은 것」, `current-sprint.md` 는 「아직 안 끝난 것」이고
런칭은 **진행 중인 일**이다(`current-sprint.md:5`).

**그런데 `backlog.md` 쪽이 더 자세했다.** 지우기만 하면 내용을 잃는다. 다섯 문자열을 계수해 확인했다.

| 문자열 | `current-sprint.md` | `backlog.md` |
| --- | ---: | ---: |
| `localhost:8080` (프로덕션 번들에 박혀 있음) | **1건** | 0건 |
| `CORS 로 전 API 차단` | **1건** | 0건 |
| `assets/index-` | **1건** | 0건 |
| `통짜로 실행된 적이 없다` | **1건** | 0건 |
| `TUNNEL_TOKEN` | **1건** | 0건 |

다섯 전부 정본으로 옮겨졌고 `backlog.md` 에는 **정본을 가리키는 한 줄**만 남았다.
**중복을 지우면서 내용을 잃으면 고치려던 문제보다 나쁜 결과가 되므로** 이 계수를 증거로 남긴다.

### 실행하지 않은 것 — 숨기지 않고 적는다

문서에 적은 `#37` 의 `curl` 은 **실 `OPENAI_API_KEY` 가 필요해 돌리지 못했다.**

**「적어 두고 돌려보지 않은 명령」이 하나 남았다** — 키가 들어오는 날 그 한 줄이 첫 동작이다.
