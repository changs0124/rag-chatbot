# 변경 전 — 테스트가 타입 검사를 안 거친다

측정 커밋 : `origin/main` (`9bc52c4`) · 프로덕션 코드 무수정

## 구멍

```json
// frontend/tsconfig.app.json
"exclude": ["src/**/*.test.ts", "src/**/*.test.tsx", "src/test"]
```

vitest 는 esbuild 로 트랜스파일만 하고 타입을 보지 않는다. 즉 **테스트 파일 9개가 어느 게이트도 거치지 않는다.**

## 현재 상태 — 전부 초록이다

```text
$ npx tsc -b            EXIT=0
$ npm test              케이스 76, 실패 0
```

**거짓인 타입을 아무도 막지 못한다.**

## exclude 를 걷으면 오류 3건

```text
$ npx tsc -p tsconfig.app.json --noEmit      (exclude 를 [] 로)
src/components/ErrorBoundary.test.tsx(14,10): error TS2786: 'Boom' cannot be used as a JSX component.
  Its type '() => void' is not a valid JSX element type.
src/hooks/useChat.test.ts(181,24): error TS2554: Expected 1 arguments, but got 0.
src/hooks/useChat.test.ts(201,37): error TS2554: Expected 1 arguments, but got 0.
```

**3건 그대로다** — #25 에서 잰 값과 같다.

## 셋 중 둘째가 가장 값어치 있다

`useChat.test.ts` 가 `onDone?.()` 을 **인자 없이** 부른다. 실제 계약은 이렇다.

```text
frontend/src/lib/endpoints.ts:63    onDone?: (data: { finishReason: string; noSource: boolean }) => void
frontend/src/lib/endpoints.ts:152   handlers.onDone?.(data as { finishReason: string; noSource: boolean })
backend/.../ChatService.java:205    sendQuietly(emitter, "done", Map.of("finishReason", "stop", "noSource", …))
```

**프로덕션은 페이로드를 넘기는데 테스트는 빈 호출로 통과해 왔다.** 테스트가 실제 호출 형태를 재현하지 못하고 있었다.

첫째는 성격이 다르다 — `function Boom() { throw ... }` 의 추론 반환 타입이 `void` 라 JSX 컴포넌트로 못 쓴다. 런타임은 멀쩡하다(항상 던지므로).

## 이 구멍을 아는 게이트가 이미 우회로를 만들어 두었다

```text
scripts/check-response-contract.sh 머리 주석
  프론트를 **두 곳** 보는 이유 : tsconfig.app.json 이 src/**/*.test.tsx 를 exclude 하고 vitest 는
  타입 검사를 하지 않아, AdminPage.test.tsx 의 doc() 픽스처는 어느 게이트도 거치지 않는다.
  RagDocument 에 필수 필드를 하나 더해도 npm run build 와 케이스 74개가 전부 통과했다(#25 실측).
```

게이트 하나가 이 구멍을 메우려고 픽스처를 따로 대조하고 있다.

## CI 는 어떻게 검사하나

```text
.github/workflows/ci.yml:67   - name: Build (tsc + vite)  →  npm run build
frontend/package.json:11      "build": "tsc -b && vite build"
frontend/tsconfig.json        references: tsconfig.app.json, tsconfig.node.json
```

**`tsc -b` 가 `tsconfig.app.json` 을 탄다.** exclude 만 걷으면 **CI 스텝을 추가하지 않아도** 자동으로 검사된다.
