## 무엇이 문제였나

`check-all.sh` 의 `skip()` 은 도구가 없어 검사를 건너뛸 때 **그 사실을 크게 남기려고** 만든 함수다. `CONVENTIONS.md:136-137` 이 그 동작을 명시한다 — "조용히 넘어가면 「통과」와 「검사 안 함」이 구분되지 않는다".

그런데 포맷 문자열에 변환 지정자가 없었다.

```bash
printf '""N""' "$1" "$2"     # ← %s 가 없다
```

```
$ skip "시크릿 스캔" "gitleaks 없음"
출력: [""N""]                 ← 인자 둘이 조용히 버려진다
```

**문서가 맞고 코드가 틀린 상태였다.**

## 왜 아무도 못 알아챘나

요약부는 `SKIPPED` **배열을 따로 순회**하므로 최종 요약에는 건너뜀이 제대로 나온다. 검사가 도는 **도중의 한 줄만** 깨진 것이라 눈에 띄지 않았다.

그리고 이걸 잡아 줄 게이트가 없다 — `bash -n` 은 구문 오류가 아니라 **통과하고**, `shellcheck` 는 SC2183 으로 정확히 잡지만 이 저장소에는 셸 검사 자체가 없다(#136 에서 다룬다).

## 고친 것

```bash
printf '\n\033[1m▶ %s\033[0m\n' "$1"
printf '\033[33m  - 건너뜀: %s\033[0m\n' "$2"
```

형태는 `run()` 과 맞췄다 — 호출부에서 `run` 자리에 그대로 들어가기 때문이다.

## 전후

**변경 전**

```
출력: [""N""]
```

**변경 후**

```
▶ 백엔드 이미지 빌드
  - 건너뜀: docker 없음

▶ 시크릿 스캔
  - 건너뜀: gitleaks 없음

SKIPPED 배열 2건:
  백엔드 이미지 빌드 - docker 없음
  시크릿 스캔 - gitleaks 없음
```

## 검증

| 완료 기준 | 결과 |
|---|---|
| 검사 이름과 사유가 포함된 줄이 출력된다 | 충족 |
| 인자 두 개가 모두 나타난다 | 충족 (리터럴 `""N""` 사라짐) |
| `SKIPPED` 배열·요약부·종료 코드 처리 불변 | 배열 2건 그대로 쌓임. 해당 코드는 미수정 |
| `bash -n scripts/check-all.sh` | 통과 |

변경은 **`scripts/check-all.sh` 한 파일 6줄**이다.

## 발견 경위

#133 의 후속 검토 과정에서 나왔다. #136(셸 구문 검사 게이트)과 원인이 다르다 — #136 은 "게이트가 없다"는 구조 문제이고, 이것은 **그 공백 때문에 살아남은 실제 결함**이다.
