변경 후 — skip() 이 검사 이름과 사유를 모두 출력한다

소스
skip() {
	# **`%s` 둘을 반드시 남긴다(#138).** 종전 포맷 문자열에는 변환 지정자가 없어
	# 인자 둘이 조용히 버려지고 리터럴만 찍혔다 - 이 함수가 존재하는 이유인 "건너뛴 사실을
	# 크게 남긴다"가 정작 동작하지 않았다. `bash -n` 은 구문 오류가 아니라 통과한다(#136).
	# 형태는 `run()` 과 맞춘다 - 호출부에서 `run` 자리에 그대로 들어가기 때문이다.
	printf '\n\033[1m▶ %s\033[0m\n' "$1"
	printf '\033[33m  - 건너뜀: %s\033[0m\n' "$2"
	SKIPPED+=("$1 - $2")
}

단독 실행 (ANSI 이스케이프는 제거해 표시)

▶ 백엔드 이미지 빌드
  - 건너뜀: docker 없음

▶ 시크릿 스캔
  - 건너뜀: gitleaks 없음

SKIPPED 배열 2건:
  백엔드 이미지 빌드 - docker 없음
  시크릿 스캔 - gitleaks 없음

완료 기준 대조
  ① 검사 이름과 사유가 포함된 줄이 출력된다      → 충족
  ② 인자 두 개가 모두 나타난다                   → 충족 (리터럴 ""N"" 사라짐)
  ③ SKIPPED 배열·요약부·종료 코드 처리 불변      → 배열 2건 그대로, 해당 코드 미수정
  ④ bash -n 통과                                 → 통과
