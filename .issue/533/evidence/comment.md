## #533 리포트 — 지시문 끝에 요청 시점 날짜(KST)를 붙인다

**변경** — `OpenAiRealService` : 검색 도구가 붙은 턴의 `instructions` = 고정 `RAG_INSTRUCTIONS` + 날짜 줄
「- 오늘은 2026-11-04(수, 한국 시간)이다. 「이번 달 · 지난달 · 최근 N개월 · 올해」 같은 상대 시점은 이 날짜를 기준으로 풀고, 어느 기간으로 풀었는지 답에 밝힌다.」

- **끝에 붙인 이유** : 프롬프트 캐시는 앞부분 일치로 잡힌다 — 날마다 바뀌는 것은 마지막 한 줄뿐. 사용자 입력은 건드리지 않는다(검색어에 날짜가 섞이지 않게)
- **시간대** `Asia/Seoul` 고정 — 서버 시계(UTC) 날짜면 KST 00~09시가 전날. 테스트는 고정 Clock 으로 UTC 15:30(= KST 다음 날 00:30) · 14:59 양쪽을 본다
- 스토어가 없어 지시문을 싣지 않는 모드는 그대로(날짜도 없음)

**실측**(운영 스토어 · 운영 서버에서 OpenAI 직접, 실제 Java 문자열을 javac 로 뽑아 사용, 오늘 2026-11-04)
