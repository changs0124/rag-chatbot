## 후속 리포트 — 갤럭시에서 카메라 항목이 없던 문제

커밋 `3abffe2` · 브랜치 `fix/289-android-camera-chooser`

### 사용자 실기기 확인 (2026-10-15)

- iPhone : `+` → 「사진 찍기 · 사진 보관함 · 파일 선택」 3개가 나왔다 — **정상**
- 갤럭시 : `+` → 카메라 없이 **사진 보관함으로 바로 들어갔다**

### 원인

#218 은 촬영 항목을 빼려고 파일 입력의 `accept` 를 서버 허용 목록(`image/jpeg,image/png,image/webp,image/gif`)으로 좁혀 두었다. iOS 는 그래도 촬영 항목을 붙이지만, Android 크롬은 이 값을 따라 보관함만 연다. 앱 안 카메라를 없앤 뒤로는 갤럭시에 촬영할 방법이 없어진다.

### 바꾼 것

- `accept="image/*"`. 그러면 Android 도 카메라와 보관함 중에 고르는 창을 띄운다.
- 허용 밖 형식(HEIC 등)이 들어오면 업로드 단계에서 서버가 거절하고, 첨부 카드에 「지원하지 않는 파일 형식」이 남는다. 드롭 · 붙여넣기와 같은 경로다. iOS 는 이 설정에서 HEIC 를 JPEG 로 바꿔 넘긴다.
- 테스트 : 「선택창은 `image/*` 로 연다」. 변경 전에는 실패했다(`before-android/test_accept.txt`). 프론트 156/156
- `frontend.md` · CHANGELOG

OS 선택창 자체는 자동화로 찍을 수 없다. **배포 뒤 갤럭시에서 카메라 항목이 나오는지 다시 봐 주셔야 한다.**
