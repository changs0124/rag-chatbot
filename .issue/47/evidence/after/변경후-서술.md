## 우선순위 재배치

`docs/04_tasks/backlog.md` **「보통」 → 「높은 우선순위」**.

기존 「높은 우선순위」 둘(OpenAI 실 연동 · Vector Store 구축)은 **실 OpenAI 키가 없어 지금 손댈 수 없는** 항목이다. 이 항목은 막힌 것이 없고, 방치하면 게이트가 막히는 시점을 외부(새 CVE 공개)가 정한다.

## CI 영향 — 확인한 것

- `scripts/check-runtime-versions.sh` 는 `java.version`(17) 만 검사한다. **Spring Boot 버전은 보지 않으므로 이 게이트는 영향 없음** — 스크립트를 직접 읽고 확인했다
- `deps (백엔드 의존성 취약점)` 잡이 실제 위험 지점이고, **지금은 통과 중**이다. "이미 막혔다" 가 아니라 **"막히는 시점을 우리가 못 고른다"** 가 정확한 서술이며, 문서에도 그렇게 적었다
