# before — 기동 직후 죽은 app 컨테이너에서 deploy.sh 192행이 하는 일 (로컬 재현, Docker 29.8.2)
$ docker compose up -d   # app 이 바로 exit 1
 Container rp252-app-1 Started 
$ docker compose ps -q app        # 192행이 쓰는 것
[]  ← 비어 있음
$ docker inspect -f "{{.Image}}" $(docker compose ps -q app)
docker: 'docker inspect' requires at least 1 argument

→ docker inspect 가 인자 없음으로 실패(0 이 아닌 종료 코드). deploy.sh 원격 스크립트는 set -e 라 여기서 멈추고, 헬스체크 실패 출력(로그 · OOM · :previous 되돌리기 안내)을 못 본다

$ docker compose ps -a -q app     # 고친 뒤 쓸 것
[23d8c5c673aa]  ← 죽은 컨테이너도 나온다
