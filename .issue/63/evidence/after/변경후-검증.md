## 9곳 전부 `asString(기본값)` — 기본값 없는 호출이 남지 않았다

```text
:242  ev.path("type").asString("")          ← 가드 없는 최악 지점
:244  ev.path("delta").asString("")
:302  item.path("type").asString("")
:304  r.path("filename").asString("")
:306  r.path("text").asString("")           ← 원래 기본값 있었음. API 통일
:312  ann.path("type").asString("")
:313  ann.path("filename").asString("")
:389  uploaded.path("id").asString(null)    ← 원래 기본값 있었음
:421  node.path("status").asString("")      ← 원래 기본값 있었음
```

**한 파일에 두 API 가 섞이지 않게** 이미 기본값을 주던 3곳도 함께 옮겼다.

## `:389` 의 버그 수정을 되돌리지 않았다

`asString(null)` 이 `asText(null)` 과 같은 동작임을 실측했다.

```text
NULL.asString(null)    = null
MISSING.asString(null) = null
STRING.asString(null)  = abc
```

`{"id": null}` 이 오면 여전히 `null` 이 되어 가드에 걸린다. **되돌리지 않도록 그 이유를 코드 옆에 주석으로 남겼다** — Jackson 2 시절 문자열 `"null"` 이 가드를 통과해 `openai_file_id = "null"` 인 행을 만들었다는 것.
