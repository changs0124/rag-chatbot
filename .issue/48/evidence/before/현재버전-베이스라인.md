## 릴리스 확인 — 검색 API 가 아니라 저장소를 봤다

Maven Central **검색 API(solrsearch) 인덱스는 낡아서** 지금 쓰는 `3.5.16` 조차 나오지 않았다(최신이 3.5.3 으로 보임). 그래서 `repo1.maven.org` 의 `maven-metadata.xml` 을 직접 읽었다.

```text
spring-boot-starter-parent   … 4.0.8, 4.1.0, 4.1.1, 4.2.0-M1      → 최신 GA = 4.1.1
mybatis-spring-boot-starter  … 3.0.5, 4.0.0, 4.0.1, 4.1.0         → Boot 4.1 대응 = 4.1.0
```

**둘 다 릴리스돼 있어 막힌 것이 없다.** MyBatis 가 Boot 4.1 을 못 따라왔으면 이 작업 자체가 보류였다.

## Boot 4.1.1 BOM 이 끌고 오는 메이저 넷

`spring-boot-dependencies-4.1.1.pom` 에서 읽은 값이다.

```text
jackson-bom.version      3.1.5     (jackson-2-bom.version 2.21.5 도 병행 관리)
junit-jupiter.version    6.0.3
testcontainers.version   2.0.5
flyway.version           12.4.0
mockito.version          5.23.0
postgresql.version       42.7.13   ← 우리가 수동으로 박은 값과 정확히 같다
```

**`postgresql.version` 수동 고정은 이제 불필요하다.** 남겨 두면 앞으로 BOM 이 더 올려도 우리가 낮은 값에 묶어 두게 되어, 원래 고정한 이유(보안)와 반대로 작동한다.

## 구 starter 이름 존재 확인

